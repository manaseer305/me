نبذة عني

أنا طالب في تخصص هندسة البرمجيات في جامعة فيلادلفيا. خلال مسيرتي الأكاديمية والعملية، طورت شغفاً كبيراً بتصميم وهندسة الأنظمة التي تلبي احتياجات المستخدمين بشكل دقيق.

أمتلك خبرة في تطوير واجهات المستخدم (Front-end) باستخدام أحدث التقنيات، بالإضافة إلى بناء الأنظمة الخلفية (Back-end) وقواعد البيانات لضمان أداء عالٍ وموثوقية، مع التركيز الخاص على بيئة عمل .NET و تقنيات الويب.

المهارات التقنية

C# WPF HTML5 CSS3 / Tailwind JavaScript SQL Server Git / GitHub
